# Security Policy

## Reporting a Vulnerability

Please do not publicly disclose suspected security vulnerabilities through
GitHub Issues.

If you discover a security issue, report it privately through GitHub Security
Advisories when available.

Please include:

- A clear description of the issue
- Affected files or components
- Reproduction steps
- Potential impact
- Suggested mitigation, if known

## Security Scope

Security-sensitive areas in this repository may include:

- Model and checkpoint loading
- Serialization and deserialization
- Dataset and file ingestion
- Dependency management
- File-system access
- Inference utilities
- Training workflows
- Community-contributed code

## Disclosure

Please allow reasonable time for review and remediation before public
disclosure.

## Supported Versions

Security fixes will primarily target the latest maintained version of this
repository.
